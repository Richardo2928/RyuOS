# Profiles

This directory contains the possible profiles for the homes module. Each profile serves as a specific configuration for a specific use case.

## soRyu - profile

This is the **core** profile for any Ryu installation. It contains the most basic packages and configurations.

## shinRyu - profile

This profile is designed to be my main (and personal) profile with my most used or favorite packages.

## Suites resource-based profiles

The following profiles are designed to be used in conjunction with the core profile. They are meant to provide packages and configurations for specific use cases (targeting different device capabilities).

### kozoraRyu - profile

This profile is designed for low-end devices with limited resources. It contains packages and configurations that are optimized for performance and minimal resource usage.

### oozoraRyu - profile

This profile is designed for high-end devices with ample resources. It contains packages and configurations that take advantage of the device's capabilities.
